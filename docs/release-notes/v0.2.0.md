# Roleplay Relay v0.2.0

The app now tells you when a new version is out. Your saved settings, keys, prompts and hotkeys did not change.

## What changed

- **Update notifier (check only).** From this version on, the app tells you when a new version is out. Once a day it asks the GitHub API for the number of the latest release. Nothing else is sent: no chat text, settings or keys. The app never downloads or installs anything by itself.
- **How you learn about it:** one Windows notification per version, the tray item `Download version …` at the top of the tray menu, and an update strip plus status line in `Settings`.
- **Settings → `General`:** new checkbox `Check for updates` (on by default), the line `Installed version: …`, and the buttons `Check now` and `Download`.
- **Updating:** `Quit` from the tray, click `Download`, run the installer. Your settings, keys, prompts and characters are kept.

See `docs/USER_GUIDE.md` sections 2, 8, 10 and 11.

## Never touches the game

Roleplay Relay only reads and writes the system clipboard, listens to global hotkeys and shows its own windows. It never simulates input, installs input hooks, reads game memory or files, or looks for the game window. You paste and press Enter yourself.

Use at your own risk. No tool can guarantee your game account won't be actioned. You are responsible for every message sent from your account.
