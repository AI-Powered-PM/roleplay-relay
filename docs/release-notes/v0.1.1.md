# Roleplay Relay v0.1.1

Settings window pass, OpenAI out of beta, and clearer long replies. Hotkeys, defaults and requests did not change. The `rp.md` and `direct.md` prompts and the "too long" message did.

## What changed

- **Settings: clearer hotkey names and hints.** `Translate clipboard` → `Translate copied line`, `Compose reply` → `Open reply window`, `Quick clipboard mode` → `Convert copied text`. Hotkeys themselves did not change.
- **Settings: new layout.** Status banner, `Test key`, only the active provider is shown, model settings moved to Advanced, overlay preview, sticky Save. No setting was reset; your keys, hotkeys and models are kept.
- **Settings → Advanced:** the hint under the Claude models table now explains why Temperature says `ignored` and how to change the reply style instead (edit `rp.md` or `persona.md`).
- **OpenAI is no longer beta.** It has been tested with a real OpenAI account on every flow. In Settings it is now just `OpenAI`.
- **Long replies:** the "too long" message now shows how many chat messages the reply needs and what to do. RP mode now knows the chat limit and keeps replies closer to the length of what you wrote.

See `docs/USER_GUIDE.md` sections 3 and 6–8 for the new window.

## Never touches the game

Roleplay Relay only reads and writes the system clipboard, listens to global hotkeys and shows its own windows. It never simulates input, installs input hooks, reads game memory or files, or looks for the game window. You paste and press Enter yourself.

Use at your own risk. No tool can guarantee your game account won't be actioned. You are responsible for every message sent from your account.
