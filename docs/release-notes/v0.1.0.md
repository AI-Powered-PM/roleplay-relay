# Roleplay Relay v0.1.0

Roleplay Relay (RP chat helper) is a Windows tray app that helps a non-native English speaker roleplay in an online game's text chat. It translates incoming chat into your language, and turns what you write into natural English you can paste into the game.

**Bring your own API key — usage is billed to your account.**

## Features

- **Incoming translate** (`Ctrl+Alt+T`): copy a chat line, get a translation in your language in the overlay.
- **Compose** (`Ctrl+Alt+R`): write in your language, get English back. Three modes: Direct, RP and Grammar.
- **Quick mode** (`Ctrl+Alt+E`): run the last used mode on text already in the clipboard.
- **Long-message split** (`Ctrl+Alt+N`): replies over the chat limit are split at sentence boundaries; copy the next part with one key.
- **Overlay history** (`Ctrl+Alt+O`): show the last 10 entries.
- **5 user languages:** Deutsch, 简体中文, Français, Español, Русский.

## AI providers

- **Anthropic (Claude)** is the default.
- **OpenAI (beta)** is tested against a mock server only.

## Never touches the game

Roleplay Relay only reads and writes the system clipboard, listens to global hotkeys and shows its own windows. It never simulates input, installs input hooks, reads game memory or files, or looks for the game window. You paste and press Enter yourself.

Use at your own risk. No tool can guarantee your game account won't be actioned. You are responsible for every message sent from your account.
